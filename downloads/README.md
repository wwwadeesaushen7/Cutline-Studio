# Complete Windows download

[Download Cutline-Studio-Windows.zip](https://github.com/wwwadeesaushen7/Cutline-Studio/raw/refs/heads/main/downloads/Cutline-Studio-Windows.zip)

This contains the complete website source, built interface, setup/open launchers, and latest editing updates. No earlier ZIP is required. Extract All, open **Cutline Studio**, run **1 - Setup**, then **2 - Open Cutline**. Read **START-HERE.txt** inside the package.

First setup requires internet for dependencies. Your videos, environment settings, credentials, and installed tools are excluded from this package.

Maintainers: after building the frontend, refresh the package with `python scripts/package_windows.py --output downloads/Cutline-Studio-Windows.zip`. Commit the ZIP and its `.sha256` checksum together with the source changes.
