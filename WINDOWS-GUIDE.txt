CUTLINE STUDIO - WINDOWS GUIDE
=============================

This download lets you use Cutline in your browser on your own Windows PC.
Windows 10/11, 64-bit, and internet access are needed for the first setup.
Setup prepares the website automatically. You do not need to write code or use Git.

1. EXTRACT THE DOWNLOAD
   Open your Downloads folder.
   Right-click the downloaded ZIP file and choose "Extract All".
   Click "Extract".
   Open the extracted folder that contains "1 - Setup.bat".
   Do not run the files while they are still inside the ZIP.

2. RUN SETUP ONCE
   Double-click "1 - Setup.bat".
   A terminal window opens and shows its progress.
   It installs missing tools directly, verifies their checksums/signatures,
   and keeps portable Node.js and FFmpeg inside the .tools folder.
   It then downloads the app's Python packages using verified HTTPS.
   If you downloaded the source from GitHub, it also builds the website.
   If an installer asks for Windows permission, review it and choose Yes
   to continue. Setup can take several minutes depending on your internet.
   Wait for "SETUP COMPLETE", then close that window.

3. OPEN THE WEBSITE
   Double-click "2 - Open Cutline.bat".
   Your browser opens Cutline automatically after startup.
   Keep the terminal window open while you use Cutline.
   To stop it, go to that window and press Ctrl+C.
   Each time you want to use Cutline again, use "2 - Open Cutline.bat".

4. CREATE YOUR FIRST CLIP
   Click "Browse files" and choose a video LONGER than 3 minutes.
   For your first test, use a clear English speaking video around 4 minutes.
   Leave the default settings, then click "Create my clips".
   Wait for processing. The first video may download the Whisper model.
   If that model is unavailable, the bundled recognizer handles English.
   When clips are ready, click "Make it yours" on a clip.
   Choose captions, add your text or music, and select "Download quality":
   480p for smaller files, 720p HD for balanced quality, or 1080p Full HD.
   Then click "Export clip".
   When "Your MP4 is ready" appears, click it to download the clip.

CHOOSING DOWNLOAD QUALITY
   Click the download arrow on a clip in My projects.
   Choose 480p, 720p HD, or 1080p Full HD under "Download quality".
   Click "Prepare download" and wait, then click "Download 1080p MP4"
   (or the quality you chose). The existing quality can be downloaded directly.
   Your saved framing, captions, text, and music are kept.
   The same quality selector is above "Export clip" in Make it yours.
   Higher quality takes longer and creates larger files. It cannot restore
   details missing from a low-quality original video.

5. CUT A SPECIFIC TIME RANGE
   Click "Clip a time range" on the main screen or in the left menu.
   Upload your video, or paste a public YouTube link.
   Enter the start and end times. For example, 00:30 to 01:15 cuts 45 seconds.
   With an uploaded file, use the player and "Use playhead" buttons to set
   your times, then "Preview selected range" to check the selection.
   Turn off "Auto captions" for the quickest cut, or enable it for subtitles.
   Click "Cut this range". The single clip appears in My projects.
   This mode also accepts videos shorter than 3 minutes and silent videos.

CHOOSING THE FRAMING
   "Full scene - people & objects" keeps the whole picture visible, including
   other people and things the speaker shows. A soft background fills the
   extra space when a wide video is placed in a vertical frame.
   "Auto - speakers & split screens" chooses the layout automatically.
   "Speaker cuts - active face" cuts straight to the detected speaker's face.
   Speaker changes have no slide, drag, fade, or animated camera movement.
   "Two screens - top & bottom" shows both pictures at once. A source with
   side-by-side screens becomes left screen on top, right screen underneath.
   Set Source layout to "Already top / bottom" for a source already stacked.
   Adjust the divider if the source panels have different sizes.
   If Auto guesses incorrectly, choose Two screens or Full scene yourself.
   Face/speaker detection can make mistakes, so check the exported video.
   Turn off "Follow the speaker" for a fixed center crop in Speaker cuts mode.
   To update an existing clip, use "Make it yours", open the Frame tab, choose
   a framing option, and click "Export clip". Changes apply to that export.

IF SOMETHING DOES NOT WORK
   Setup version 2 does not need App Installer, Microsoft Store, or WinGet.
   The setup window should say "DIRECT SETUP (VERSION 2)". If it does not,
   download the updated ZIP from GitHub and extract it into a new folder.
   If Windows or your organisation blocks running scripts, stop and ask
   your administrator. Do not disable Windows security protections.
   For an error, send a screenshot of the error window in the chat.
   Setup does not require a Python or AI account or a paid API key.
   YouTube may reject some downloads. Try uploading the video file instead.
   Speech recognition can make mistakes. Check your clips before sharing.

UPDATING AN EXISTING COPY
   Close the black terminal window that is running Cutline first.
   Download the updated ZIP from GitHub and use "Extract All".
   Open the extracted app folder that contains "1 - Setup.bat".
   Copy all files and folders INSIDE it into your existing Cutline folder.
   Choose "Replace the files in the destination" when Windows asks.
   Copying these files preserves your .data, .tools, and .venv folders.
   Run "1 - Setup.bat" again to build the updated website interface.
   Existing tools are reused. Wait for "SETUP COMPLETE".
   Use "2 - Open Cutline.bat" again afterward.
   Failed projects now offer "Retry processing" when their video is saved.
   Click it to continue without another upload. Completed clips are kept.
   If the source file is gone, upload the video again.

WHERE YOUR VIDEOS GO
   Projects and clips are stored in the hidden .data folder alongside this
   guide. Use Cutline's Delete Project button to remove a project and files.
   Keep this folder if you want to keep your projects.

ABOUT A PUBLIC WEBSITE
   This runs on your computer. To give other people a website link, the app
   still needs a separate hosting setup. No hosting account is needed to
   test it on your Windows PC.

TESTING NOTE
   The website and processing have been tested in the Linux cloud machine.
   Windows package availability and launcher logic were checked, but this
   environment cannot execute Windows .bat files. Report any Windows error
   so it can be corrected.

FINE-TUNE A CLIP AND FIX CAPTIONS
   1. In My projects, click "Make it yours" on your clip.
   2. Open Trim. Set the start/end in seconds, or move the video playhead
      and click "Set start here" / "Set end here". Keep at least 0.25 sec.
      "Restore full clip" brings the whole original clip back.
   3. Open Captions, then "Edit caption words". Correct any wrong words.
      Clear a word to hide it. You can search for a word in a long clip.
   4. Keep your text, music, framing, and download quality as you want.
      Click "Export clip" and wait for "Your MP4 is ready".
   5. Click "Exported video" to watch the actual finished result.
      Download the MP4, or "Download captions (.srt)" for subtitles.
   Your original clip is kept. Saved edits return when you reopen it.
   Changing download quality keeps those saved edits.
